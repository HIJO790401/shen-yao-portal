# 站主 CMS 與合作聯絡｜執行計畫

1. 稽核現有 Studio、新聞、責任博物館、D1、R2 與站主身分驗證。
2. 先修正非站主在資料讀取前未被阻擋的順序，以及本機 Host 判斷邊界。
3. 加入固定收件人的合作表單；只開啟訪客自己的郵件程式，不保存、不代寄。
4. 加固新聞與館藏寫入：同源、長度、slug、狀態、日期、封面、影片與證據網址驗證。
5. 加固圖片：只接受 JPEG、PNG、WebP，檢查實際檔案簽章與 8 MB 上限，禁止 SVG。
6. 補齊更新／刪除不存在資料的 404 與 slug 重複的 409。
7. 建立專案內 canonical license 與本機可重用 Codex 技能駕照；禁止秘密入庫。
8. 跑 typecheck、lint、production build、契約測試與右側可瀏覽 UI 驗收。
9. 只提交本次範圍，保留未使用素材與 rollback，依站主授權直接推送 `main`。
10. 不儲存 Sites version、不部署、不碰網域；正式登入與 D1/R2 CRUD 保留到部署階段驗證。
