# 開場影片交付規格

站主只需要提供最後的影片檔，不需要改網站程式。

## 建議成品

- 長度：8–12 秒。
- 畫面：16:9，建議 1920 × 1080。
- 格式：H.264 MP4，像素格式 yuv420p，24 或 30 fps。
- 網路播放：啟用 faststart。
- 檔案大小：建議不超過 12–15 MB。
- 聲音：可有 AAC 音軌；網站會以靜音自動播放，訪客仍可自行開啟聲音。
- 安全構圖：水滴、標誌與重要文字放在畫面中央區域，避免手機 `object-fit: cover` 裁掉。

## 接入方式

1. 將檔案命名為 `serene-school-intro.mp4`。
2. 放到 `public/media/intro/serene-school-intro.mp4`，或提供可公開讀取的 HTTPS MP4／WebM 網址。
3. 設定：

   `NEXT_PUBLIC_INTRO_VIDEO_URL=/media/intro/serene-school-intro.mp4`

4. 未設定或播放失敗時，網站會自動回復站主核准的水滴封面。

遠端影片網址會進入公開網頁；不得在網址中放帳號、密碼、私人權杖或其他秘密。建議使用無須登入且可長期公開讀取的網址。

## 已鎖定的互動規則

- 影片可靜音自動播放，但不會自動把訪客送進官網。
- 左下方／操作區永遠保留「進入官網」按鈕。
- 訪客不必等影片播完。
- 影片錯誤時不會卡住，也不會生成替代影片。
- `prefers-reduced-motion`、鍵盤操作與行動裝置維持可用。

狀態：`OWNER_VIDEO_PENDING`
